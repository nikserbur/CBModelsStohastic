# CBModelsStohastic

[English version](README.md)

Исследовательский код на R и C++ для стохастических расширений моделирования процентных ставок в России с учётом тяжёлых хвостов. В нём есть диагностика хвостов распределений, поправка R² на тяжёлые хвосты, HAR-волатильность, режимы скрытой марковской модели и расширенное правило Тейлора со сценариями Монте-Карло для ставки RUONIA.

Код к статье: Бураков Н. С. [Стохастическое моделирование денежно-кредитной политики: модульная архитектура для анализа экстремальных сценариев](http://scipro.ru/article/07-03-2026) // International Journal of Professional Science. 2026. № 3-1. С. 47–66.

## Что есть в репозитории

Статья описывает модульный конвейер:
- латентные факторы на основе копульной нормализации и SVD;
- HAR / стохастическая волатильность с калибровкой хвостовых распределений;
- скрытая марковская модель (HMM) для переключения режимов;
- расширенное правило Тейлора как оператор реакции политики;
- веерные диаграммы Монте-Карло с метриками хвостового риска (VaR / CTE);
- оценка качества через R² Талеба.

## Исправления после публикации

Версия кода в репозитории содержит исправления, внесённые после публикации статьи. Поэтому числа в статье, полученные прежней версией кода, могут отличаться от того, что выводит эта версия.

- **R² Талеба.** `CalculateRobustR2()` (в `all_fun.R` и `4.LmR2BoostingStohastic.R`) применяла множитель $\nu/(\nu-2)$ дважды. Теперь он применяется один раз (см. [R² Талеба](#поправка-r-на-тяжёлые-хвосты-4lmr2boostingstohasticr)). `Main.R` теперь выводит R² Талеба 0.89 для базового правила Тейлора и 0.97 для расширенного вместо 0.78 и 0.94. Меняются также веса Шепли и значения R² Талеба в `DataAnalysisAndRegression.R`.
- **Логарифм правдоподобия HMM.** `ForwardBackward()` возвращала только логарифм первой нормирующей константы. Это влияло на правило остановки EM и на AIC / BIC в `5.HiddenMarkingsModels.R`. В `Main.R` оценки параметров HMM не изменились до третьего знака, квантили симуляций — до шестого.
- **Хвостовой риск и калибровка.** VaR / CTE считаются по каждому горизонту по всем траекториям, добавлены функции CRPS / PIT. Прежний черновик считал эти статистики по траекториям и вызывал несуществующую `pit_sample()`.
- **Отбор признаков RDC.** Оценка в `RDCSelection_cpp()` заменена на RDC и перестановочное p-значение.
- **Генератор α-устойчивых величин в `FastMonteCarlo.cpp`.** Формула Чемберса–Мэллоуза–Стака была записана неверно, и все значения получались положительными. `Main.R` этот генератор не использует.

## Требования

- **R ≥ 4.0.** Все скрипты проверены на R 4.4.1 под macOS.
- **Пакеты R.** [`1.R/9.libraries.r`](1.R/9.libraries.r) устанавливает недостающие пакеты из CRAN и подключает все пакеты. Его подключает `all_fun.R` (а значит, и `8.SourceAll.R`).
  - `3.dist_bust.R` сам подключает `9.libraries.r`. `4.LmR2BoostingStohastic.R`, `10.DashboardData.R` и `Demo_Volatility_Analysis.R` подключают свои пакеты через `library()`.
  - `EstimateHarModel()` использует также `car` и `lmtest`. Необязательное сравнение с XGBoost в `DataAnalysisAndRegression.R` выполняется, только если установлен `xgboost`.
  - Пакет `qs` необязателен. CRAN перенёс его в архив 17.01.2026. Скрипты сохраняют результаты через `SaveProjectResults()`: если `qs` установлен, она вызывает `qs::qsave()` (файл `.qs`), иначе `saveRDS()` (файл `.rds` с тем же именем). Для `BuildDistDashboard(save_qs_path = …)` пакет `qs` по-прежнему нужен.
- **Компилятор C++** (для [`2.Cpp/`](2.Cpp)). Для `Rcpp::sourceCpp()` нужен компилятор C++:
  - macOS: Xcode Command Line Tools (`xcode-select --install`);
  - Windows: версия Rtools, соответствующая вашей версии R;
  - Linux: `g++` и заголовочные файлы R для разработки (например, `build-essential` и `r-base-dev` в Debian/Ubuntu).
  
  `all_fun.R` компилирует `FastMonteCarlo.cpp` при подключении. Если компиляция не удалась, выводится сообщение и используются реализации на R.
- **Рабочая директория.** Все пути к файлам в скриптах указаны относительно корня репозитория. Откройте [`CB_models_stohastic.Rproj`](CB_models_stohastic.Rproj) в RStudio, вызовите `setwd()` с корнем репозитория или запускайте `Rscript 1.R/<скрипт>.R` из корня.
- **Локаль.** У трёх файлов данных кириллические имена, и скрипты читают их по буквальному пути. Запускайте R в локали UTF-8 (например, `LANG=en_US.UTF-8`). В локали C, а также в R до версии 4.2 под Windows такие пути не находятся.

**Ежемесячная панель (`prep_data()`).**
- Панель охватывает 02.2017 – 08.2025 (103 месяца). Она строится от ряда рыночной волатильности: для каждого дня берётся среднее абсолютное отклонение суммы уровней индексов MOEX и RTS за последние 30 торговых дней, умноженное на $\sqrt{30}$, и усредняется по месяцу.
- Остальные файлы присоединяются по месяцу. Значение RUONIA за август 2025 года — среднее за 1–12 августа, потому что файл заканчивается 12 августа.
- Каждый пропуск заменяется подогнанным значением линейной регрессии ряда на время по всей панели. Поэтому ряды, которые заканчиваются раньше (например, ВВП после марта 2025 года), продлеваются линейным трендом.

Скрипты записывают результаты в `3.Data/*.qs` или `3.Data/*.rds`. Эти файлы перечислены в `.gitignore`.

## Порядок запуска

Из корня репозитория:

```bash
Rscript 1.R/Main.R                       # интегрированная модель; сохраняет 3.Data/final_integrated_cb_model.qs (.rds)
Rscript 1.R/5.HiddenMarkingsModels.R     # HMM ключевой ставки с 5 состояниями
Rscript 1.R/DataAnalysisAndRegression.R  # регрессии RUONIA и ИПЦ на панель
Rscript 1.R/Demo_HAR_Volatility.R        # HAR-волатильность RUONIA со стохастическим коридором
Rscript 1.R/Demo_SVD_Forecasting.R       # прогнозирование через SVD на смоделированных данных
Rscript 1.R/3.dist_bust.R                # диагностика хвостов на смоделированных данных
Rscript 1.R/4.LmR2BoostingStohastic.R    # стандартный R² и R² с поправкой на тяжёлые хвосты на смоделированных данных
Rscript 1.R/10.DashboardData.R           # дашборд распределения на шести смоделированных выборках
Rscript 1.R/Demo_Volatility_Analysis.R   # HAR и GARCH(1,1) на смоделированных доходностях
```

Графики создаются как объекты plotly. Чтобы их увидеть, запустите скрипт в интерактивной сессии, например `source("1.R/Main.R", print.eval = TRUE)`, и выведите `beautiful_plot`, `model_comparison_plot`, `transition_heatmap` и т. д.

Файлы C++ можно скомпилировать отдельно:


## Метод

В этом разделе описано то, что реализует код. Обозначения во всём тексте едины:

| Символ | Значение |
|---|---|
| $\nu$ | Хвостовой индекс / число степеней свободы распределения Стьюдента (`ALPHA_TAIL`, `alpha_tail` в коде) |
| $\alpha$ | Индекс устойчивости α-устойчивого закона |
| $c$ | Уровень доверия для VaR / CTE (в `Main.R` $c = 0.95$) |
| $K$ | Число состояний HMM |

### Диагностика хвостов (`3.dist_bust.R`)

Скрипт генерирует $N = 100\,000$ наблюдений из трёх процессов с базовой волатильностью $\sigma_0 = 0.3$:
- **нормальный:** $X \sim N(0, \sigma_0^2)$;
- **стохастическая волатильность:** $X \mid s \sim N(0, s^2)$, где $s = \sigma_0 e^{\eta}$ и $\eta \sim N(0, 0.6^2)$;
- **смесь:** с вероятностью 0.01 $X \sim N(0, (5\sigma_0)^2)$, иначе $X$ — наблюдение со стохастической волатильностью.

Для каждой выборки скрипт выводит:
- $P(|X| > k\sigma_0)$ для $k = 2, \dots, 5$; пороги заданы в единицах $\sigma_0$, а не выборочного стандартного отклонения;
- нормальный ориентир $2(1 - \Phi(k))$;
- эксцесс (в определении Пирсона, для нормального распределения он равен 3), среднее и дисперсию;

### Поправка R² на тяжёлые хвосты (`4.LmR2BoostingStohastic.R`)

**Модель для симуляции.** Скрипт генерирует $n = 10\,000$ наблюдений модели

$$y = 2 + 1.5\,x_1 - 0.8\,x_2 + \varepsilon, \qquad x_1 \sim N(0, 1), \quad x_2 \sim N(0, 1.5^2),$$

с тремя типами остатков:
- **нормальные:** $\varepsilon \sim N(0, 0.5^2)$;
- **с тяжёлыми хвостами:** $\varepsilon = 0.45\,t_\nu$ при $\nu = 2.8$, где 4 % наблюдений умножаются на 3.5;
- **смесь:** с вероятностью 0.07 — наблюдение $1.5\,t_3$, иначе $N(0, 0.5^2)$.

**Формула Талеба.** Для $y = a x + s\,\varepsilon$ при $\operatorname{Var}(x) = 1$ и стандартной ошибке Стьюдента $\varepsilon \sim t_\nu$ дисперсия ошибки равна $s^2\nu/(\nu-2)$. Тогда R² генеральной совокупности

$$R^2 = \frac{a^2}{a^2 + s^2\,\nu/(\nu-2)} = \frac{\tilde a^2(\nu-2)}{\tilde a^2(\nu-2) + \nu}, \qquad \tilde a^2 = a^2/s^2,$$

это выражение Талеба (2020) при $s = 1$.

**Варианты R².** После МНК функция `CalculateRobustR2(y, ŷ, ν)` вычисляет три значения. Здесь $\hat\varepsilon_i = y_i - \hat y_i$, а $\hat s$ — масштаб распределения Стьюдента с $\nu$ степенями свободы, подогнанного к $\hat\varepsilon$ при фиксированном $\nu$ (`EstimateStudentScale()`: метод максимального правдоподобия через `MASS::fitdistr()`; если оценка не удалась — $\operatorname{MAD}(\hat\varepsilon)/t_\nu^{-1}(0.75)$):

$$R^2_{\text{std}} = 1 - \frac{\sum_i \hat\varepsilon_i^2}{\sum_i (y_i - \bar y)^2},$$

$$R^2_{\text{Taleb}} = \frac{\widehat{\operatorname{Var}}(\hat y)}{\widehat{\operatorname{Var}}(\hat y) + \frac{\nu}{\nu - 2}\,\hat s^2}, \qquad R^2_{\text{MLE}} = \max\left(0,\; 1 - \frac{n\,\frac{\nu}{\nu - 2}\,\hat s^2}{\sum_i (y_i - \bar y)^2}\right).$$

- Множитель $\nu/(\nu-2)$ переводит квадрат масштаба распределения Стьюдента в дисперсию, поэтому он применяется к $\hat s^2$ один раз. Выборочная дисперсия $\hat\varepsilon$ уже оценивает $s^2\nu/(\nu-2)$, и повторно на этот множитель она не умножается. Прежние версии кода умножали её повторно (см. [Исправления после публикации](#исправления-после-публикации)).
- $R^2_{\text{MLE}}$ заменяет в $R^2_{\text{std}}$ средний квадрат остатков $\sum_i\hat\varepsilon_i^2/n$ на дисперсию ошибки подогнанной t-модели.
- Оба скорректированных значения равны 0 при $\nu \le 2.1$, а $R^2_{\text{Taleb}}$ обрезается до отрезка $[0, 1]$. Версия в `all_fun.R` вместо этого использует $\max(\nu, 2.1)$ в $R^2_{\text{Taleb}}$, возвращает $R^2_{\text{std}}$ в качестве $R^2_{\text{MLE}}$ при $\nu \le 2$ и обрезает все три значения до $[0, 1]$.
- Скрипт использует $\nu = 30$ для нормальных остатков, $\nu = 2.8$ для остатков с тяжёлыми хвостами и $\nu = \max(4,\, 0.8 \cdot 2.8) = 4$ для смеси.

**Поведение.**
- Для нормальных ошибок при $\nu = 1000$ значение $R^2_{\text{Taleb}}$ совпадает с классическим R² (0.4972 и 0.4972 в симуляции с $n = 10\,000$).
- Для ошибок Стьюдента с $\nu = 3, 4, 6$ оно отличается от R² генеральной совокупности не более чем на 0.01.
- Остатки скрипта с тяжёлыми хвостами и остатки-смесь не являются остатками Стьюдента: 4 % выбросов и смесь завышают выборочную дисперсию, а t-модель подгоняется в основном по центральной части данных. Для этих двух типов остатков скрипт выводит скорректированные значения выше стандартного R² (0.82 против 0.70 и 0.90 против 0.81).

**Оценка Хилла.** Скрипт также выводит оценку Хилла для хвостового индекса $|\hat\varepsilon|$ по $k = \min(100, \lfloor n/4 \rfloor)$ наибольшим значениям $X_{(1)} \ge X_{(2)} \ge \dots$:

$$\hat\nu_{\text{Hill}} = \left(\frac{1}{k} \sum_{i=1}^{k} \ln X_{(i)} - \ln X_{(k+1)}\right)^{-1}.$$

### HAR-волатильность (`Demo_Volatility_Analysis.R`)

**Данные.** Скрипт генерирует 2 500 дневных доходностей. Волатильность следует рекурсии типа GARCH с четырьмя кризисными окнами, календарными эффектами и эффектом левериджа. При высоком множителе волатильности инновации переключаются на распределение Стьюдента; кроме того, добавлено 15 дней флэш-крэшей. Первые 2 200 дней используются для обучения, последние 300 — для теста.

**Прокси реализованной волатильности:**

$$RV_t = \sqrt{252}\,\sum_{i=0}^{21} r_{t-i}^2.$$

**HAR для log-RV** (Corsi, 2009). Модель оценивается функцией `highfrequency::HARmodel()` с горизонтами $h \in \{1, 5, 22, 91, 365, 730\}$ дней:

$$\ln RV_{t+1} = \beta_0 + \sum_{h} \beta_h\, \overline{\ln RV}{}_t^{(h)} + u_{t+1}, \qquad \overline{\ln RV}{}_t^{(h)} = \frac{1}{h}\sum_{i=0}^{h-1} \ln RV_{t-i}.$$

В исходной спецификации Корси используются $h \in \{1, 5, 22\}$. Логарифмическое преобразование комментарии в коде приписывают Clements и Preve.

**Прогноз.** Прогноз строится по одному шагу на 300 дней вперёд. На каждом шаге модель переоценивается на расширенном ряду, и прогноз переводится обратно через $\exp(\cdot)$. Затем прогноз умножается на эвристические множители, которые заданы в коде, а не оценены:
- случайные шоки, вероятность которых складывается из исторической частоты шоков, 350-дневного цикла, календарных эффектов и отклонения недавней логарифмической волатильности;
- поправки на режим от 0.95 до 1.2.

**Стохастический коридор.** Скрипт моделирует 1 000 траекторий процесса волатильности с возвратом к среднему вокруг HAR-прогноза. В коде этот процесс назван процессом типа Хестона и приписан Lu (2022), полная ссылка на которого в коде не приведена. Параметры: $\kappa = 0.5$, $\sigma_v = 0.3$, леверидж $-0.5$; вес HAR-прогноза равен $0.6 + 0.2e^{-t/5}$. Скрипт выводит квантили от 1 % до 99 % для каждого дня по всем траекториям.

**Эталон и точность.** Эталон — модель GARCH(1,1) с нормальными инновациями (`rugarch`), приведённая к годовым значениям как $\hat\sigma_t\sqrt{252}$. Скрипт сравнивает MSE, MAE и MAPE на тестовом окне.

### Прогнозирование через SVD (`PredictTimeSeriesWithSVD()`; `Demo_SVD_Forecasting.R`, `Main.R`)

Для таблицы числовых рядов:
1. Каждый ряд длиной не меньше двух сезонных периодов раскладывается STL (`stl(s.window = "periodic", robust = TRUE)`) на тренд и сезонную часть.
2. Добавляются синусы и косинусы с годовой, полугодовой и квартальной частотой. Матрица стандартизируется z-оценками (без копульного преобразования).
3. SVD оставляет наименьший ранг, при котором сингулярные числа покрывают не менее 95 % энергии $\sum_j d_j^2$.
4. Каждый оставленный левый сингулярный вектор экстраполируется функцией `ExtrapolateLatentFactorWithSeasonality()`.
   - Сначала функция пробует `vars::VAR()` для отдельной компоненты. `vars::VAR()` не принимает одиночный ряд («The matrix 'y' should contain at least two variables»), поэтому на практике управление переходит к обработчику ошибки.
   - Обработчик оценивает `ar(method = "yule-walker", order.max = 2)`. Если и это не удаётся, используются `forecast::ets()`, а затем линейный тренд.
5. Компоненты собираются обратно через правые сингулярные векторы, стандартизация снимается. Каждый ряд возвращается как сумма тренда и сезонной части.

`Demo_SVD_Forecasting.R` применяет функцию к пяти смоделированным месячным рядам (120 месяцев, последние 24 отложены для проверки). `Main.R` применяет её к 70 числовым столбцам панели с горизонтом 19 месяцев (на текущих данных ранг 8, 95.8 % энергии).

### Режимы HMM (`5.HiddenMarkingsModels.R`)

**Данные.** Ежемесячная ключевая ставка $r_t$ начиная с января 2014 года, а также:
- инфляция ИПЦ;
- кредитный импульс;
- ВВП;
- ожидаемая инфляция.

Пропуски заполняются через `zoo::na.spline()`. Скрипт вычисляет:
- отклонение инфляции от цели 4 %;
- разность ключевой ставки и инфляции;
- рост ВВП г/г;
- отношение кредитного импульса к ВВП;
- месячное изменение ключевой ставки.

**Модель.** Модель с марковским переключением в смысле Hamilton (1989): $K = 5$ скрытых состояний $S_t$, матрица переходов $P_{jk} = P(S_{t+1} = k \mid S_t = j)$ и гауссовские эмиссии $r_t \mid S_t = k \sim N(\mu_k, \sigma_k^2)$. Функции находятся в `all_fun.R`:
- `InitializeHmmParameters()`: начальные значения по k-means, на диагонали $P$ стоит 0.8;
- `EstimateHmmParameters()`: EM-алгоритм Баума–Велша (здесь не более 50 итераций, точность $10^{-6}$) с ограничением $\sigma_k \ge 0.1$. После оценки состояния упорядочиваются по возрастанию $\mu_k$;
- `ViterbiDecoding()`: наиболее вероятная последовательность состояний.

**Качество модели.**

$$\mathrm{AIC} = -2\ell + 2(K^2 + 2K), \qquad \mathrm{BIC} = -2\ell + \ln(T)\,(K^2 + 2K),$$

Здесь $\ell$ — логарифм правдоподобия, сумма логарифмов нормирующих констант масштабированного прямого прохода, а $T$ — число наблюдений. Устойчивость режимов — среднее $\operatorname{diag}(P)$.

**Оговорки:**
- Метки «Ultra-Accommodative», «Accommodative», «Neutral», «Restrictive» и «Crisis» присваиваются по номеру состояния. Поскольку состояния упорядочены по $\mu_k$, метки идут от состояния с наименьшей средней ключевой ставкой к состоянию с наибольшей.
- Анимация «истории обучения» синтетическая. Её кадры линейно интерполируют между случайной стохастической по строкам матрицей и итоговой оценкой, а показанный логарифм правдоподобия равен итоговому значению минус 2 на каждый оставшийся кадр. Реальных итераций оценивания анимация не показывает.

### Интегрированная модель (`Main.R`)

Все константы ниже заданы в `Main.R` или `all_fun.R`. Горизонт $H = 19$ месяцев, $N = 10\,000$ траекторий, цель по инфляции $\pi^* = 4\,\%$.

1. **Панель и прогнозы факторов.** `prep_data()` собирает панель (см. [Данные](#данные)). Обучающая выборка заканчивается последним месяцем, в котором есть RUONIA, ИПЦ и ВВП (на текущих данных — август 2025 года, после заполнения пропусков). `PredictTimeSeriesWithSVD()` прогнозирует все числовые столбцы на $H$ месяцев.
   - Производные переменные: $\pi_t - \pi^*$ (`inflation_deviation`); разрыв выпуска $g_t = 100\,(Y_t - Y_t^*)/Y_t^*$ с трендом LOESS $Y_t^*$ (span 0.3); скользящее 6-месячное стандартное отклонение RUONIA $v_t$ (`rate_volatility`); кредитный импульс / ВВП; разность ключевой ставки и инфляции.
2. **Калибровка распределений** (`CalibrateStochasticDistributions()`) методом максимального правдоподобия:
   - волатильность: $\Delta v_t = \kappa(\theta - v_{t-1}) + \sigma_v\sqrt{v_{t-1}}\,\eta_t$, $\eta_t \sim N(0,1)$;
   - инфляция ИПЦ и разрыв выпуска: распределение Стьюдента или Парето, выбор по AIC;
   - остатки МНК-регрессии RUONIA на $\pi_t - \pi^*$ и $g_t$: α-устойчивый закон $S(\alpha, \beta, \gamma, \delta)$ (`stabledist::dstable`).
3. **HAR-волатильность.** `highfrequency::HARmodel(periods = c(5, 22))` по месячному ряду $v_t$. Модель переоценивается после каждого шага, и строится цепочка из 19 прогнозов на один шаг.
4. **Режимы HMM.**
   - Наблюдения — композитный индикатор, взвешенная сумма z-оценок всех числовых столбцов панели. `gdp_gap`, `B002`, `credit_to_gdp`, `budget_impulse`, `policy_tightness` и `ruonia_rate` получают вес 0.07 каждый, остальные столбцы поровну делят 0.58.
   - $K = 7$ состояний, EM-алгоритм Баума–Велша не более чем на 1 000 итераций, затем декодирование Витерби.
   - Прогнозные вероятности режимов строятся от состояния 7: $p(h) = e_7^\top P^{\,h-1}$ (`PredictRegimeProbabilities(current_state = 7)`).
5. **Правило Тейлора.**
   - `CalibrateTaylorRuleParameters()` оценивает $i_t = \rho\, i_{t-1} + (1-\rho)\,[r^* + \phi_\pi(\pi_t - \pi^*) + \phi_y g_t] + \varepsilon_t$, $\varepsilon_t \sim N(0, \sigma^2)$, методом максимального правдоподобия.
   - Затем `Main.R` оставляет $\rho = 0.8$ вместо оценённого значения и снижает $r^*$ на 2 процентных пункта (`NEUTRAL_RATE_ADJUSTMENT`).
   - Расширенное правило — МНК-регрессия RUONIA на её лаг, $\pi_t - \pi^*$, $g_t$, HAR-волатильность, фиктивную переменную режима 7, ожидаемую инфляцию и кредит / ВВП.
   - Оценка Хилла для хвостового индекса остатков базового правила, обрезанная до $[1.1, 4]$ (`EstimateAlphaParameter()`), используется как $\nu$ в R² Талеба и как $\alpha$ моделируемых ошибок.
   - `ComputeShapleyR2()` даёт упрощённое разложение R² Талеба по Шепли. Для каждой переменной она усредняет R² модели с одной этой переменной и падение R² при её исключении из полной модели, а затем нормирует значения к сумме 1.
6. **Монте-Карло** (`IntegratedStochasticCBModel()` в версии из `Main.R`). Для $t = 1, \dots, H$ на каждой траектории:
   - волатильность: $V_t = 0.6\,\mathrm{HAR}_t + 0.4\,[V_{t-1} + \kappa(\theta - V_{t-1}) + \sigma_v\sqrt{V_{t-1}}\,\eta_t]$;
   - факторы: $\tilde\pi_t = 0.7\,\hat\pi_t + 0.3\,\xi^\pi_t$ и $\tilde g_t = 0.7\,\hat g_t + 0.3\,\xi^g_t$, где $\hat\pi_t, \hat g_t$ — SVD-прогнозы, а $\xi$ — значения из откалиброванных законов Стьюдента или Парето;
   - нейтральная ставка: $r^*_t = r^*_0 + (7 - r^*_0)(1 - e^{-0.35t}) + \sum_k \mu_k\, p_k(t)$, где $\mu_k$ — средние эмиссий HMM, а $p_k(t)$ — прогнозные вероятности режимов;
   - $L_t = r^*_t + \sum_j b_j e^{-\kappa_j t} X_{j,t}$: коэффициенты расширенного правила $b_j$ при $\tilde\pi_t$, $\tilde g_t$, $V_t$, ожидаемой инфляции $-\,\pi^*$ и кредите / ВВП, затухающие с $\kappa_j = 0.25, 0.15, 0.20, 0.20, 0.10$;
   - $r_t = \min\big(40, \max(0.1,\; \rho_{\text{ext}}\, r_{t-1} + (1-\rho_{\text{ext}})\,L_t + e_t)\big)$, где $\rho_{\text{ext}}$ — коэффициент при лаге в расширенном правиле, обрезанный до $[0.4, 0.85]$, а $e_t \sim S(\alpha, 0, 0.5\sqrt{V_t}, 0)$ с $\alpha$, обрезанным до $[1.01, 1.99]$.
   
   Смоделированная последовательность режимов начинается с последнего состояния Витерби и следует $P$. Она сохраняется, но в уравнении ставки используются только $p_k(t)$. Параметры α-устойчивого закона, откалиброванные на шаге 2, в симуляции не используются.
7. **Оценка.** Для каждого горизонта $h$ через $F_h$ обозначено эмпирическое распределение 10 000 смоделированных ставок $r_{t+h}$. Все статистики ниже считаются по всем траекториям для каждого горизонта.
   - **Веерная диаграмма:** квантили $F_h$ уровней 5, 10, 25, 50, 75, 90 и 95 %.
   - **VaR / CTE** (`ComputeTailRiskByHorizon()`). Рассматривается риск *роста* ставки, поэтому обе метрики берутся в верхнем хвосте. При уровне доверия $c$:

     $$\mathrm{VaR}_c(h) = F_h^{-1}(c) = \inf\{x : F_h(x) \ge c\}, \qquad \mathrm{CTE}_c(h) = \mathbb{E}\left[r_{t+h} \mid r_{t+h} > \mathrm{VaR}_c(h)\right].$$

     Здесь CTE совпадает с CVaR. Для риска снижения ставки те же определения применяются к $-r_{t+h}$.
   - **CRPS и PIT** (`EvaluatePredictiveSample()`) для горизонтов, где есть фактическое значение $y_h$:
     - $\mathrm{CRPS}(F_h, y_h) = \int (F_h(x) - \mathbf 1\{x \ge y_h\})^2\,dx$ (Gneiting, Raftery, 2007), через `scoringRules::crps_sample()`;
     - $\mathrm{PIT}_h = F_h(y_h)$; рандомизация $F_h(y_h^-) + U\,[F_h(y_h) - F_h(y_h^-)]$ применяется только при совпадении смоделированных значений с $y_h$ (Czado, Gneiting, Held, 2009).

     В `scoringRules` нет функции PIT, поэтому PIT считается напрямую. `Main.R` берёт фактические значения из полных месяцев файла RUONIA. Текущий файл заканчивается до начала прогнозного периода, поэтому шаг пропускается с сообщением.
   - Детерминированный ориентир (`CreateBaselineForecasts()`): 0.3 × среднее за последние 21 месяц + 0.4 × линейный тренд за последние 24 месяца + 0.3 × правило Тейлора с затухающими разрывами.
   - Результаты сохраняются в `final_results` (`3.Data/final_integrated_cb_model.qs` или `.rds`), в том числе `tail_risk` и `forecast_evaluation`.

### Регрессии на панели (`DataAnalysisAndRegression.R`)

Для RUONIA и инфляции ИПЦ скрипт оценивает МНК-регрессию на все «исходные» числовые столбцы панели, то есть на все, кроме перечисленных в скрипте производных. Он выводит R², скорректированный R², AIC, BIC и R² Талеба, где $\nu$ — оценка Хилла для хвоста остатков.

### Отбор признаков на основе RDC (`2.Cpp/RDCScpp.cpp`)

Файл экспортирует в R две функции. Они следуют коэффициенту случайной зависимости (Randomized Dependence Coefficient, RDC) из работы Lopez-Paz, Hennig и Schölkopf (2013).

**`cancor_cpp(x, y)`** принимает две числовые матрицы с одинаковым числом строк.
- Для вырожденных входных данных возвращает нулевой результат: меньше 2 строк, нет столбцов или есть столбец с дисперсией меньше $10^{-12}$.
- В остальных случаях возвращает `stats::cancor(x, y)` (`cor`, `xcoef`, `ycoef`, …).

**`RDCSelection_cpp(data, target = NULL, threshold = 0.1, k_features = 20, num_permutations = 500)`** принимает `data` — таблицу данных из числовых столбцов. Каждый признак $x$ сравнивается с `target`; без целевой переменной — со случайно выбранным другим признаком. Для каждой пары $(x, y)$ функция:
1. заменяет `NA` и бесконечные значения на 0 и вычисляет копула-преобразование $u = R(x)/n$ (ранги; для совпадающих значений — средний ранг);
2. строит $k$ = min(`k_features`, $n - 1$) случайных признаков $\sin\big(\tfrac{s}{2}(w_i u + b_i)\big)$ с $(w_i, b_i) \sim N(0, 1)$ и $s = 1/6$. У каждого признака одна пара $(w_i, b_i)$, общая для всех наблюдений. Для $y$ делается то же со своими весами;
3. берёт RDC — наибольшую каноническую корреляцию $\hat\rho$ между двумя наборами признаков (`rdc_scores`);
4. при `num_permutations` $= B > 0$ переставляет строки признаков $y$ $B$ раз и возвращает p-значение $p = \big(1 + \#\{\hat\rho_{\text{perm}} \ge \hat\rho\}\big)/(1 + B)$ (`p_values`).

**Отбор.** С перестановками признак оставляется при $p \le$ `threshold`, то есть `threshold` — уровень значимости. Независимые признаки тогда оставляются с вероятностью около `threshold`. Без перестановок признак оставляется при $\hat\rho \ge$ `threshold`. На конечной выборке RDC положителен и при независимости (около 0.2 для независимых признаков в примере ниже), поэтому для отбора следует использовать режим с перестановками.

Функция возвращает `data` (отобранные столбцы и целевую переменную), `rdc_scores`, `p_values` (`NA` без перестановок), `selected_features`, `removed_features` и `threshold`. У внутреннего генератора случайных чисел фиксированное зерно 123, поэтому для одних и тех же данных результаты детерминированы.

В симуляции на 50 наборах данных ($n = 200$, порог 0.1, 100 перестановок) линейный и нелинейный регрессоры были оставлены во всех 50 наборах, а два независимых регрессора — в 10 % и 12 % наборов.

Пример (запуск из корня репозитория):

```r
Rcpp::sourceCpp("2.Cpp/RDCScpp.cpp")

set.seed(1)
n  <- 300
df <- data.frame(x1 = rnorm(n), x2 = rnorm(n), x3 = runif(n))
df$y <- sin(2 * df$x1) + 0.1 * rnorm(n)   # y зависит только от x1 (нелинейно)

sel <- RDCSelection_cpp(df, target = "y", threshold = 0.1,
                        k_features = 20, num_permutations = 200)
sel$rdc_scores          # x1 0.975, x2 0.208, x3 0.193
sel$p_values            # x1 0.005, x2 0.229, x3 0.522
sel$selected_features   # "x1" "y"

cc <- cancor_cpp(as.matrix(df[, c("x1", "x2")]), as.matrix(df[, "y", drop = FALSE]))
cc$cor                  # каноническая корреляция (корреляции), как в stats::cancor
```

### Вспомогательные функции на C++ (`2.Cpp/FastMonteCarlo.cpp`)

- `FastAlphaStableSimulation()` генерирует величины $S(\alpha, \beta, \gamma, \delta)$ (параметризация 1, как `stabledist::rstable(pm = 1)`) методом Чемберса–Мэллоуза–Стака в форме Weron (1996).
- `FastCompoundPoissonSimulation()` генерирует составные пуассоновские суммы нормальных скачков.
- `FastIntegratedStochasticSimulation()` моделирует траектории с марковскими режимами, взвешенными факторами, гауссовскими шоками и симметричными α-устойчивыми скачками с пуассоновским числом. Её вызывает `OptimizedMonteCarlo()`, которая возвращает матрицу «горизонт × траектория».
- `FastHarVolatilityCalculation()` вычисляет скользящие средние за 1, 5, 22 и 66 периодов.
- `FastForwardBackwardAlgorithm()` возвращает сглаженные вероятности состояний, а `FastLogLikelihood()` — логарифм правдоподобия HMM.

Эти функции инициализируют генератор через `std::random_device`, поэтому их результаты не зависят от `set.seed()`. `Main.R` их не вызывает.

### Известные ограничения

- `TestAllFunctions()` и `RunComprehensiveTests()` вызывают `PrepareHarData()`, которая не определена, поэтому их тест HAR всегда завершается ошибкой. Обработчики ошибок записывают результат в локальную копию списка, поэтому неудачные тесты не попадают в возвращаемый список, а не отображаются как проваленные. Число пройденных тестов может превышать число тестов («8 из 7»).
- В `Main.R` функция `CreateRegimeEvolutionPlot()` выполняется внутри `tryCatch()` и при ошибке молча заменяется упрощённым графиком.
- На текущих данных оценка α-устойчивого закона в `CalibrateStochasticDistributions()` упирается в верхнюю границу $\alpha = 2$.
