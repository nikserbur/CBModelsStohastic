# CBModelsStohastic

[English version](README.md)

Исследовательский код на R и C++ для стохастических расширений моделирования процентных ставок в России с учётом тяжёлых хвостов: диагностика хвостов распределений, поправка R² на тяжёлые хвосты, HAR-волатильность, режимы скрытой марковской модели и расширенное правило Тейлора со сценариями Монте-Карло для ставки RUONIA.

Код к статье: Бураков Н. С. [Стохастическое моделирование денежно-кредитной политики: модульная архитектура для анализа экстремальных сценариев](http://scipro.ru/article/07-03-2026) // International Journal of Professional Science. 2026. № 3-1. С. 47–66.

## Что есть в репозитории

Статья описывает модульный конвейер:
- латентные факторы на основе копульной нормализации и SVD;
- HAR / стохастическая волатильность с калибровкой хвостовых распределений;
- скрытая марковская модель (HMM) для переключения режимов;
- расширенное правило Тейлора как оператор реакции политики;
- веерные диаграммы Монте-Карло с метриками хвостового риска (VaR / CTE);
- оценка качества через R² Талеба.

В репозитории есть только часть этого конвейера:

## Требования

- **R ≥ 4.0.** Четыре самостоятельных скрипта и пример на C++ ниже проверены на R 4.4.1 под macOS.
- **Пакеты R.** В [`1.R/9.libraries.r`](1.R/9.libraries.r) перечислены все пакеты, которые используют скрипты. При вызове `source()` этот файл устанавливает недостающие пакеты из CRAN и подключает все пакеты.
  - `4.LmR2BoostingStohastic.R` и `Demo_Volatility_Analysis.R` подключают свои пакеты сами через `library()`.
  - Пакет `qs` необязателен. Он нужен только для аргумента `save_qs_path` функции `BuildDistDashboard()`. CRAN перенёс его в архив 17.01.2026, поэтому, если этот аргумент нужен, установите пакет из архива CRAN.
- **Компилятор C++** (только для [`2.Cpp/RDCScpp.cpp`](2.Cpp/RDCScpp.cpp)). Для `Rcpp::sourceCpp()` нужен компилятор C++:
  - macOS: Xcode Command Line Tools (`xcode-select --install`);
  - Windows: версия Rtools, соответствующая вашей версии R;
  - Linux: `g++` и заголовочные файлы R для разработки (например, `build-essential` и `r-base-dev` в Debian/Ubuntu).
- **Рабочая директория.** Все пути к файлам в скриптах указаны относительно корня репозитория. Откройте [`CB_models_stohastic.Rproj`](CB_models_stohastic.Rproj) в RStudio или вызовите `setwd()` с корнем репозитория.

| Символ | Значение |
|---|---|

### Диагностика хвостов (`3.dist_bust.R`)

Скрипт генерирует $N = 100\,000$ наблюдений из трёх процессов с базовой волатильностью $\sigma_0 = 0.3$:
- **нормальный:** $X \sim N(0, \sigma_0^2)$;
- **стохастическая волатильность:** $X \mid s \sim N(0, s^2)$, где $s = \sigma_0 e^{\eta}$ и $\eta \sim N(0, 0.6^2)$;
- **смесь:** с вероятностью 0.01 $X \sim N(0, (5\sigma_0)^2)$, иначе $X$ — наблюдение со стохастической волатильностью.

Для каждой выборки скрипт выводит:
- $P(|X| > k\sigma_0)$ для $k = 2, \dots, 5$; пороги заданы в единицах $\sigma_0$, а не выборочного стандартного отклонения;
- нормальный ориентир $2(1 - \Phi(k))$;
- эксцесс (в определении Пирсона, для нормального распределения он равен 3), среднее и дисперсию;
- QQ-графики относительно нормального распределения и гистограммы $\log|X|$.

### Поправка R² на тяжёлые хвосты (`4.LmR2BoostingStohastic.R`)

**Модель для симуляции.** Скрипт генерирует $n = 10\,000$ наблюдений модели

$$y = 2 + 1.5\,x_1 - 0.8\,x_2 + \varepsilon, \qquad x_1 \sim N(0, 1), \quad x_2 \sim N(0, 1.5^2),$$

с тремя типами остатков:
- **нормальные:** $\varepsilon \sim N(0, 0.5^2)$;
- **с тяжёлыми хвостами:** $\varepsilon = 0.45\,t_\nu$ при $\nu = 2.8$, где 4 % наблюдений умножаются на 3.5;
- **смесь:** с вероятностью 0.07 — наблюдение $1.5\,t_3$, иначе $N(0, 0.5^2)$.

**Варианты R².** После МНК функция `CalculateRobustR2(y, ŷ, ν)` вычисляет три значения R². Здесь $\hat\varepsilon_i = y_i - \hat y_i$:

$$R^2_{\text{std}} = 1 - \frac{\sum_i \hat\varepsilon_i^2}{\sum_i (y_i - \bar y)^2},$$

$$R^2_{\text{Taleb}} = \frac{\widehat{\operatorname{Var}}(\hat y)}{\widehat{\operatorname{Var}}(\hat y) + \frac{\nu}{\nu - 2}\,\widehat{\operatorname{Var}}(\hat\varepsilon)}, \qquad R^2_{\text{MLE}} = \max\left(0,\; 1 - \frac{\nu}{\nu - 2}\cdot\frac{\sum_i \hat\varepsilon_i^2}{\sum_i (y_i - \bar y)^2}\right).$$

- Оба скорректированных значения равны 0 при $\nu \le 2.1$, а $R^2_{\text{Taleb}}$ обрезается до отрезка $[0, 1]$.
- Множитель $\nu/(\nu-2)$ — дисперсия стандартной случайной величины Стьюдента с $\nu$ степенями свободы.
- Скрипт использует $\nu = 30$ для нормальных остатков, $\nu = 2.8$ для остатков с тяжёлыми хвостами и $\nu = \max(4,\, 0.8 \cdot 2.8) = 4$ для смеси.

**Связь с Талебом (2020).** Комментарии в коде ссылаются на выражение Талеба $R^2 = \dfrac{a^2(\nu-2)}{a^2(\nu-2) + \nu}$. Оно верно для $y = a x + \varepsilon$ при $\operatorname{Var}(x) = 1$ и стандартной ошибке Стьюдента $\varepsilon \sim t_\nu$, потому что тогда

$$R^2 = \frac{a^2}{a^2 + \nu/(\nu-2)}.$$

Код отличается в одном. Он умножает на $\nu/(\nu-2)$ *эмпирическую* дисперсию остатков, которая уже содержит этот множитель. Поэтому скорректированные значения в коде консервативнее (ниже), чем по формуле для генеральной совокупности. В заголовке графика скрипта они названы «консервативными методами коррекции R²» (conservative R² correction methods).

**Оценка Хилла.** Скрипт также выводит оценку Хилла для хвостового индекса $|\hat\varepsilon|$ по $k = \min(100, \lfloor n/4 \rfloor)$ наибольшим значениям $X_{(1)} \ge X_{(2)} \ge \dots$:

$$\hat\nu_{\text{Hill}} = \left(\frac{1}{k} \sum_{i=1}^{k} \ln X_{(i)} - \ln X_{(k+1)}\right)^{-1}.$$

### Дашборд распределения (`10.DashboardData.R`)

`BuildDistDashboard(x)` возвращает список, в котором есть:
- рисунок plotly из шести панелей (гистограмма с ядерной и нормальной плотностями, ECDF, нормальный QQ-график, график функции выживания в log-log масштабе, график Хилла, violin/box);
- таблица статистик: моменты, квантили, медиана, MAD, p-значения тестов Жарка–Бера, Шапиро–Уилка (не более чем на 5 000 точках) и Андерсона–Дарлинга;
- оценки правого хвоста:
  - медиана оценок Хилла по диапазону $k$ в верхней доле данных `tail_fraction`;
  - показатель степенного закона из регрессии $\ln(1 - \hat F(x))$ на $\ln x$;
- словесная характеристика хвостов.

Скрипт запускает функцию на шести смоделированных выборках: нормальной, смеси нормальных, Парето, нормальной + Парето, Коши и α-устойчивой с $\alpha = 0.5$.

### HAR-волатильность (`Demo_Volatility_Analysis.R`)

**Данные.** Скрипт генерирует 2 500 дневных доходностей. Волатильность следует рекурсии типа GARCH с четырьмя кризисными окнами, календарными эффектами и эффектом левериджа. При высоком множителе волатильности инновации переключаются на распределение Стьюдента; кроме того, добавлено 15 дней флэш-крэшей. Первые 2 200 дней используются для обучения, последние 300 — для теста.

**Прокси реализованной волатильности:**

$$RV_t = \sqrt{252}\,\sum_{i=0}^{21} r_{t-i}^2.$$

**HAR для log-RV** (Corsi, 2009). Модель оценивается функцией `highfrequency::HARmodel()` с горизонтами $h \in \{1, 5, 22, 91, 365, 730\}$ дней:

$$\ln RV_{t+1} = \beta_0 + \sum_{h} \beta_h\, \overline{\ln RV}{}_t^{(h)} + u_{t+1}, \qquad \overline{\ln RV}{}_t^{(h)} = \frac{1}{h}\sum_{i=0}^{h-1} \ln RV_{t-i}.$$

В исходной спецификации Корси используются $h \in \{1, 5, 22\}$. Логарифмическое преобразование комментарии в коде приписывают Clements и Preve.

**Прогноз.** Прогноз строится по одному шагу на 300 дней вперёд. На каждом шаге модель переоценивается на расширенном ряду, и прогноз переводится обратно через $\exp(\cdot)$. Затем прогноз умножается на эвристические множители, которые заданы в коде, а не оценены:
- случайные шоки, вероятность которых складывается из исторической частоты шоков, 350-дневного цикла, календарных эффектов и отклонения недавней логарифмической волатильности;
- поправки на режим от 0.95 до 1.2.

**Стохастический коридор.** Скрипт моделирует 1 000 траекторий процесса волатильности с возвратом к среднему вокруг HAR-прогноза. В коде этот процесс назван процессом типа Хестона и приписан Lu (2022), полная ссылка на которого в коде не приведена. Параметры: $\kappa = 0.5$, $\sigma_v = 0.3$, леверидж $-0.5$; вес HAR-прогноза равен $0.6 + 0.2e^{-t/5}$. Скрипт выводит квантили от 1 % до 99 %.

**Эталон и точность.** Эталон — модель GARCH(1,1) с нормальными инновациями (`rugarch`), приведённая к годовым значениям как $\hat\sigma_t\sqrt{252}$. Скрипт сравнивает MSE, MAE и MAPE на тестовом окне.

### Режимы HMM (`5.HiddenMarkingsModels.R`; нужны отсутствующие функции)

**Данные.** Ежемесячная ключевая ставка $r_t$ начиная с января 2014 года, а также:
- инфляция ИПЦ;
- кредитный импульс;
- ВВП;
- ожидаемая инфляция.

Пропуски заполняются через `zoo::na.spline()`. Скрипт вычисляет:
- отклонение инфляции от цели 4 %;
- разность ключевой ставки и инфляции;
- рост ВВП г/г;
- кредитный импульс относительно ВВП;
- месячное изменение ключевой ставки.

**Модель.** Это модель с марковским переключением режимов в смысле Гамильтона (Hamilton, 1989). В ней $K = 5$ скрытых состояний $S_t$ и матрица переходов $P_{jk} = P(S_{t+1} = k \mid S_t = j)$. Скрипт ожидает для каждого состояния среднее $\mu_k$ и стандартное отклонение $\sigma_k$ эмиссии, то есть гауссовские эмиссии $r_t \mid S_t = k \sim N(\mu_k, \sigma_k^2)$. Работу выполняют три функции, и ни одной из них нет в репозитории:
- `InitializeHmmParameters()` задаёт начальные параметры;
- `EstimateHmmParameters()` оценивает их (не более 50 итераций, допуск $10^{-6}$);
- `ViterbiDecoding()` восстанавливает последовательность состояний.

**Качество модели.**

$$\mathrm{AIC} = -2\ell + 2(K^2 + 2K), \qquad \mathrm{BIC} = -2\ell + \ln(T)\,(K^2 + 2K),$$

Здесь $\ell$ — логарифм правдоподобия, $T$ — число наблюдений. Устойчивость режимов — среднее значение $\operatorname{diag}(P)$.

**Оговорки:**
- Метки «Ultra-Accommodative», «Accommodative», «Neutral», «Restrictive» и «Crisis» присваиваются по номеру состояния. Они осмысленны, только если код оценки упорядочивает состояния соответствующим образом, а проверить это без этого кода нельзя.
- Анимация «истории обучения» синтетическая. Её кадры линейно интерполируют между случайной стохастической по строкам матрицей и итоговой оценкой, а отображаемый логарифм правдоподобия равен итоговому значению минус 2 за каждый оставшийся кадр. Реальные итерации оценки она не показывает.
- В этом README не приводятся оценённые вероятности переходов и средние режимов, потому что кода оценки в репозитории нет.

### Расширенное правило Тейлора, хвосты и Монте-Карло (`Main.R`; черновик)

`Main.R` описывает следующие шаги. Сейчас выполняется только шаг 1 (см. [Порядок запуска](#порядок-запуска)).

1. **Ежемесячная панель.**
   - Среднемесячная RUONIA $r_t$, инфляция ИПЦ $\pi_t$, кредитный импульс, уровень ВВП $Y_t$, бюджетный ряд, ожидаемая инфляция и волатильность MOEX + RTS.
   - Пропуски заполняются сплайнами.
   - Тренд ВВП $Y_t^*$ — сглаживание LOESS (span 0.3), разрыв выпуска $g_t = 100\,(Y_t - Y_t^*)/Y_t^*$.
2. **Хвосты остатков правила политики.** Скрипт оценивает регрессию $r_t = b_0 + b_1 \pi_t + b_2 g_t + e_t$ методом МНК. Затем он подгоняет:
   - α-устойчивый закон к $\hat e_t$;
   - закон Парето к остаткам выше их 95-го перцентиля;
   - частоту превышений $\hat\lambda$.
3. **Дрифт (расширенное правило Тейлора, по Taylor, 1993).** Планируемая регрессия:
   $$\Delta r_t = \beta_0 + \beta_1(\pi_t - \pi^*) + \beta_2 g_t + \beta_3 v_t + \beta_4 s_t + \beta_5 \hat E_t[\pi] + u_t.$$
   Здесь $\pi^*$ — цель по инфляции, $v_t$ — индекс волатильности, $s_t$ — скор санкций, $\hat E_t[\pi]$ — оценка ожидаемой инфляции. Эти входные данные пока не создаются.
4. **Параметры шоков.** `stats4::mle()` максимизирует сумму трёх логарифмов правдоподобия: нормальной плотности, плотности симметричного α-устойчивого закона и пуассоновского слагаемого для превышений.
5. **Монте-Карло.** Скрипт моделирует 1 000 траекторий длиной 12 шагов:
   $$r_t = r_{t-1} + \mu_t + \sigma\,\varepsilon_t + \sum_{j=1}^{N_t} J_{t,j}, \qquad \varepsilon_t \sim N(0,1), \quad N_t \sim \mathrm{Poisson}(\lambda), \quad J_{t,j} \sim S(\alpha, 0, \gamma, 0).$$
   Здесь $\mu_t$ — оценённый дрифт, $S(\alpha, 0, \gamma, 0)$ — симметричный α-устойчивый закон с масштабом $\gamma$.
6. **Оценка.** Скрипт показывает для каждого горизонта $h$ эмпирическое распределение $F_h$ смоделированных ставок. Рассматривается риск *роста* ставки, поэтому VaR и CVaR берутся в верхнем хвосте. При уровне доверия $c$:

   $$\mathrm{VaR}_c(h) = F_h^{-1}(c) = \inf\{x : F_h(x) \ge c\}, \qquad \mathrm{CVaR}_c(h) = \mathbb{E}\left[r_{t+h} \mid r_{t+h} > \mathrm{VaR}_c(h)\right].$$

   - CVaR совпадает с условным хвостовым ожиданием (CTE), которое используется в статье.
   - Для риска снижения ставки те же определения применяются к $-r_{t+h}$.
   - Скрипт также вычисляет CRPS (Gneiting, Raftery, 2007), $\mathrm{CRPS}(F, y) = \int_{-\infty}^{\infty} \left(F(x) - \mathbf{1}\{x \ge y\}\right)^2 dx$, функцией `scoringRules::crps_sample()`.
   - Он строит веерную диаграмму квантилей 10/25/50/75/90 %.
   - В текущем виде код применяет эти статистики к столбцам матрицы траекторий $12 \times 1000$, то есть по траекториям, а не по горизонтам. Это часть незавершённого черновика.

### Отбор признаков на основе RDC (`2.Cpp/RDCScpp.cpp`)

Файл экспортирует в R две функции. Он основан на идее рандомизированного коэффициента зависимости (Randomized Dependence Coefficient; Lopez-Paz, Hennig, Schölkopf, 2013).

**`cancor_cpp(x, y)`** принимает две числовые матрицы с одинаковым числом строк.
- Для вырожденных входных данных возвращается нулевой результат: меньше 2 строк, нет столбцов или есть столбец с дисперсией меньше $10^{-12}$.
- В остальных случаях возвращается `stats::cancor(x, y)` (`cor`, `xcoef`, `ycoef`, …).

**`RDCSelection_cpp(data, target = NULL, threshold = 0.1, k_features = 20, num_permutations = 500)`** принимает `data` — data frame из числовых столбцов. Каждый признак $x$ сравнивается с `target`; если цель не задана — со случайно выбранным другим признаком. Для каждого признака функция:
1. заменяет `NA` и бесконечные значения на 0, а значения — на ранги $R(\cdot)$;
2. строит $k$ = min(`k_features`, $n - 1$) случайных признаков $\sin(w\,R(x)/n)$ и $\cos(w\,R(y)/n)$, причём $w \sim N(0, 1)$ генерируется заново для каждого наблюдения и признака;
3. берёт наибольшую каноническую корреляцию $\hat\rho$;
4. вычисляет оценку:
   - при `num_permutations` $> 0$: $\hat\rho$ пересчитывается на перестановках $y$, $f$ — доля перестановок, корреляция которых не превышает $\hat\rho$, а оценка равна $|f - 0.5|/0.5$;
   - иначе оценка равна $\hat\rho$.

Признаки с оценкой не ниже `threshold` сохраняются. Функция возвращает `data` (выбранные столбцы и цель), `rdc_scores`, `selected_features`, `removed_features` и `threshold`. Внутренний генератор случайных чисел имеет фиксированный seed 123, поэтому для одних и тех же данных результат детерминирован.

Отличия от исходного RDC:
- в оригинале каждый случайный признак использует один вес проекции (и сдвиг), общий для всех наблюдений; здесь вес генерируется заново для каждого наблюдения, а для $x$ и $y$ используются разные нелинейности ($\sin$ и $\cos$);
- при независимости $f$ распределена примерно равномерно, поэтому перестановочная оценка примерно равномерна на $[0, 1]$. Оценка, близкая к 1, может получиться и при $f \approx 0$. Используйте оценку как эвристический рейтинг, а не как статистический тест.

Пример (запуск из корня репозитория):

```r
Rcpp::sourceCpp("2.Cpp/RDCScpp.cpp")

set.seed(1)
n  <- 300
df <- data.frame(x1 = rnorm(n), x2 = rnorm(n), x3 = runif(n))
df$y <- sin(2 * df$x1) + 0.1 * rnorm(n)   # y зависит только от x1 (нелинейно)

sel <- RDCSelection_cpp(df, target = "y", threshold = 0.1,
                        k_features = 20, num_permutations = 200)
sel$rdc_scores          # по одной оценке на признак, в [0, 1]
sel$selected_features   # признаки с оценкой >= threshold, плюс цель

cc <- cancor_cpp(as.matrix(df[, c("x1", "x2")]), as.matrix(df[, "y", drop = FALSE]))
cc$cor                  # каноническая корреляция(и), как в stats::cancor
```
